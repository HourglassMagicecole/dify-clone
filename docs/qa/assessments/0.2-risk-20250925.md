### 1. DATA-001: 마이그레이션 실패로 인한 기존 Dify 데이터 손상

**Score: 9 (Critical)**
**Probability**: High (3) - Flask-Migrate가 기존 테이블과 충돌할 가능성
**Impact**: High (3) - 프로덕션 데이터 손상 시 전체 시스템 장애
**Mitigation**:
- 마이그레이션 전 전체 데이터베이스 백업 필수
- 개발 환경에서 충분한 테스트 후 적용
- 롤백 스크립트 사전 준비 및 검증
**Testing Focus**: 기존 테이블과의 충돌 테스트, 롤백 시나리오 테스트

### 2. SEC-001: education_api_keys 테이블의 API 키 평문 저장 취약점

**Score: 9 (Critical)**
**Probability**: High (3) - 암호화 구현 누락 가능성 높음
