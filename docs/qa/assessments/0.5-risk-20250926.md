## Critical Risks Requiring Immediate Attention

### 1. TECH-001: Dify API 통합 복잡성

**Score: 9 (Critical)**
**Probability**: High - 외부 시스템과의 첫 통합이며, API 스펙 변경 가능성 존재
**Impact**: High - API 통합 실패 시 전체 교육 플랫폼 작동 불가
**Mitigation**:
- API 버전 고정 및 변경 사항 모니터링
- Mock 서버 구축으로 독립적 테스트 환경 확보
- 통합 테스트 커버리지 100% 달성
- API 응답 스키마 검증 로직 구현
**Testing Focus**:
- 모든 API 엔드포인트에 대한 통합 테스트
- 네트워크 장애 시나리오 테스트
- API 버전 호환성 테스트

## High Risk Items

### 2. SEC-001: API Key 노출 위험

**Score: 6 (High)**
**Probability**: Medium - 테스트 중 실수로 키가 커밋될 가능성
**Impact**: High - 프로덕션 API 키 노출 시 심각한 보안 침해
**Mitigation**:
- .gitignore에 모든 환경 파일 추가
- GitHub Secrets 사용 필수화
- Pre-commit hook으로 시크릿 스캔
- 환경별 키 분리 (dev/staging/prod)
**Testing Focus**:
- 시크릿 스캔 도구 실행
- 환경변수 주입 테스트

### 3. PERF-001: 50명 동시 접속 부하 처리

**Score: 6 (High)**
**Probability**: High - 첫 부하 테스트로 예상치 못한 병목 발생 가능
**Impact**: Medium - 성능 저하 및 사용자 경험 악화
**Mitigation**:
- 점진적 부하 증가 테스트 (10→20→30→40→50)
- 캐싱 전략 구현 (React Query)
- 데이터베이스 인덱스 최적화
- 자동 스케일링 설정
**Testing Focus**:
- k6 부하 테스트 시나리오 실행
- 메모리 누수 모니터링
- 응답 시간 측정 (p90, p95)
