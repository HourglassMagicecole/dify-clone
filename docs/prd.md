### 개선 범위 정의

#### 개선 유형
- ✅ 새로운 기능 추가 - 교육 특화 UI/UX
- ✅ 주요 기능 수정 - 사용자 경험 재설계
- ✅ UI/UX 개편 - 비IT 전공자를 위한 완전히 새로운 인터페이스

#### 개선사항 설명
**EduAI Studio**는 Dify의 백엔드 기능을 활용하여 비IT 전공자들이 생성형 AI의 핵심 개념인 Agent와 Workflow를 직관적으로 이해하고 실습할 수 있는 교육용 플랫폼입니다. 복잡한 기술적 지식 없이도 AI 애플리케이션의 구조와 동작 원리를 체험할 수 있는 환경을 제공합니다.

#### 영향 평가
✅ **주요 영향 (아키텍처 변경 필요)** - 완전히 새로운 프론트엔드 애플리케이션 개발

### 목표 및 배경 컨텍스트

#### 목표
- 프로그래밍 경험이 없는 사용자도 쉽게 AI Agent를 구성하고 테스트
- 이론이 아닌 실제 구현을 통한 체험적 학습 제공
- 기본 개념부터 고급 기능까지 순차적 학습 경로 제공
- 실시간으로 결과를 확인하며 개념 이해
- 최대 50명이 동시에 실습 가능한 교육 환경 구축
- 교육 진행자를 위한 통합 관리 도구 제공

#### 배경 컨텍스트
현재 생성형 AI 교육은 기술적 배경이 필요한 도구들로 인해 비전공자들의 진입 장벽이 높습니다. Dify의 강력한 백엔드 기능은 유지하되, 교육에 최적화된 새로운 UI/UX를 제공하여 누구나 AI 애플리케이션의 핵심 개념을 이해하고 실습할 수 있는 환경을 구축합니다. 오프라인 대면 교육 환경에서 4-8시간 내에 완료 가능한 실습 중심의 커리큘럼을 지원합니다.

## 요구사항

### 기능 요구사항

#### Agent 관리 관련 요구사항

**FR1**: 시스템은 교육 참가자가 순차적으로 Agent를 구성할 수 있도록 5단계 가이드형 워크플로우를 제공해야 합니다:
- 1단계: 기본 설정 (Agent 이름 및 설명 입력, 대화형/작업형 유형 선택, 역할 정의)
- 2단계: 프롬프트 구성 (시스템 프롬프트 작성 with 템플릿, 변수 정의 및 설정, Few-shot 예제 추가, 실시간 프롬프트 미리보기)
- 3단계: LLM 설정 (OpenAI/Anthropic/Google 제공자 선택, GPT-4o/Claude-Sonnet/Gemini 등 모델 선택, Temperature/Max Tokens/Top-p 파라미터 조정, 멀티모달 활성화)
- 4단계: Tool/RAG 구성 (웹 검색, 계산기, 날씨 API, OCR, 이미지 생성, TTS, STT 등 내장 도구 선택, 외부 API 연동, RAG 지식베이스 연결)
- 5단계: 확인 및 테스트 (전체 구성 요약 확인, 테스트 채팅 실행, 최종 저장 및 배포)

**FR2**: Agent 관리 기능으로 편집(모든 설정 수정), 복제(템플릿으로 활용), 삭제, 읽기 전용 공유를 지원해야 합니다.

#### Workflow 관련 요구사항

**FR3**: 드래그 앤 드롭 방식의 비주얼 Workflow 편집기는 다음 11가지 노드 유형을 지원해야 합니다:
- 시작/종료 노드 (Workflow의 시작과 끝 정의)
- 입력 노드 (텍스트, 파일, 이미지 입력)
- 출력 노드 (텍스트, 파일, 이미지 출력)
- 변수 노드 (데이터 저장 및 변환)
- LLM 노드 (언어 모델 호출 및 프롬프트 처리)
- 조건 분기 노드 (IF/ELSE 로직 구현)
- 반복 노드 (리스트 처리 및 반복 작업)
- 도구 실행 노드 (외부 API 또는 내장 도구 호출)
- RAG 검색 노드 (지식베이스 쿼리)
- HTTP 요청 노드 (외부 서비스 연동)
- Agent 호출 노드 (다른 작업형 Agent 연동)

**FR4**: Workflow는 변경 이력 자동 저장, 삭제, 복제, 읽기 전용 공유 기능을 제공해야 합니다.

#### RAG 시스템 요구사항

**FR5**: RAG 파이프라인 학습 인터페이스는 각 단계를 시각화하여 동작 원리를 이해할 수 있도록 해야 합니다:
- Load: TXT/Markdown/PDF 형식 지원, 파일 업로드 인터페이스, 메타데이터 자동 추출
- Split: 청킹 전략 선택(고정 크기/문장 단위/의미 단위), 20-5000 토큰 크기 조정, 오버랩 설정, 분할 결과 시각화
- Embed: OpenAI/Cohere 임베딩 모델 선택, 벡터 차원 표시, 임베딩 생성 진행률 표시
- Store: 저장된 청크 수 및 용량 표시, 인덱스 관리 인터페이스

**FR6**: RAG 검색 테스트 시 쿼리 입력 후 관련 청크 검색, 유사도 점수 표시, 핵심 부분 하이라이팅, 리랭킹 기능을 제공해야 합니다.

**FR7**: RAG 관리 기능으로 문서 목록 및 삭제, 임베딩 재생성, 스토리지 모니터링을 제공해야 합니다.

#### Agent 실행 인터페이스 요구사항

**FR8**: 대화형 Agent 인터페이스는 다음 기능을 제공해야 합니다:
- 실시간 채팅 및 스트리밍 응답
- 멀티모달 입력 (텍스트, 이미지, 파일 업로드)
- 처리 단계 표시 (실행 중인 도구 또는 참조 중인 RAG 표시)
- 중간 결과 및 각 단계별 처리 결과 확인
- 실시간 토큰 사용량 및 비용 계산
- 각 구성 요소별 응답 시간 측정
- 대화 내보내기 (텍스트, JSON 형식)
- 응답 재생성 기능
- 대화 기록 관리 및 이전 대화 재접속
- 처리 완료 시 시각적/음성 알림

**FR9**: 작업형 Agent 인터페이스는 다음 기능을 제공해야 합니다:
- 사전 정의된 필드로 구성된 폼 기반 입력
- 다양한 파일 형식 업로드 지원
- 작업 진행 상태 표시 (대기, 처리 중, 완료, 오류)
- 처리 단계 및 중간 결과 표시
- 실패 시 작업 재시도 옵션
- 작업 내역 조회 및 재실행

#### Workflow 실행 인터페이스 요구사항

**FR10**: Workflow 실행 인터페이스는 다음을 제공해야 합니다:
- 실행 시 입력 폼 제공 (텍스트, 파일, 이미지)
- 실행 제어 버튼 (시작/중지)
- 실행 상태 표시 (대기, 실행 중, 완료, 오류)
- 각 노드별 처리 상태, 순서 및 시간 표시
- 최종 결과 출력
- 실행 내역 조회 및 재실행 기능

EduAI Studio는 Dify의 복잡한 전문가용 인터페이스를 교육 목적에 맞게 완전히 재설계합니다. 기존 Dify UI의 기술 용어 과다, 복잡한 설정 옵션, 가파른 학습 곡선 문제를 해결하여 단계별 가이드, 시각화 중심, 즉각적 피드백을 제공하는 교육 특화 UI를 구현합니다. Dify의 강력한 백엔드 기능은 그대로 유지하면서 프론트엔드만 교체합니다.

## 개발 시작 시 필요한 작업

### 데이터베이스 설계

#### 핵심 테이블 (라이센스 준수 설계)

**education_sessions**: 교육 세션 관리
- `id`: UUID PRIMARY KEY DEFAULT uuid_generate_v4()
- `name`: VARCHAR(255) NOT NULL - 세션 이름
- `session_code`: VARCHAR(20) UNIQUE NOT NULL - 참가 코드
- `instructor_id`: UUID NOT NULL (FK: accounts.id)
- `session_type`: VARCHAR(20) - ONLINE/OFFLINE/HYBRID
- `scheduled_start/end`: TIMESTAMP NOT NULL
- `max_participants`: INTEGER DEFAULT 50
- `is_active`: BOOLEAN DEFAULT true

**resource_tags**: 세션별 리소스 구분 (멀티테넌트 대체)
- `resource_type`: VARCHAR(50) - app/workflow/dataset
- `resource_id`: UUID NOT NULL
- `tag_key/tag_value`: VARCHAR - 태그 정보
- INDEX: resource_lookup, tag_search

**learning_progress**: 학습 진행률 추적
- `user_id`: UUID NOT NULL (FK: accounts.id)
- `session_id`: UUID (선택적)
- `module_code`: VARCHAR(50) NOT NULL
- `progress_percentage`: INTEGER DEFAULT 0
- `status`: VARCHAR(20) DEFAULT 'NOT_STARTED'

**education_enrollments**: 세션 참가자 관리
- `user_id`: UUID NOT NULL
- `session_id`: UUID NOT NULL
- `role`: VARCHAR(20) DEFAULT 'STUDENT'
- UNIQUE(user_id, session_id)

### API 설계
- Dify 백엔드 API 100% 재사용 (API-only 접근)
- 교육 전용 엔드포인트 추가 (/edu/api/*)
- 인증/권한은 기존 시스템 활용
