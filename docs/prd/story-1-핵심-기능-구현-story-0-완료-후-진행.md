# Story 1: 핵심 기능 구현 (Story 0 완료 후 진행)

## Story 1.1: 교육용 프론트엔드 프로젝트 초기 설정

교육 관리자로서,
새로운 교육용 프론트엔드 애플리케이션의 기반을 구축하고 싶다.
이를 통해 Dify와 독립적으로 개발하면서도 백엔드와 통합할 수 있다.

**사전 조건**: Story 0.5 완료 (인프라 및 API 검증 완료)

**수락 기준**:
1. web-edu/ 디렉토리에 Next.js 15 프로젝트 생성
2. TypeScript, ESLint, Prettier 설정 완료
3. Tailwind CSS 및 교육용 디자인 시스템 구축
   - 컴포넌트 라이브러리 기초 구축
   - 테마 시스템 구현
   - 반응형 레이아웃 시스템
4. i18n 설정 (한국어/영어)
5. Story 0.5에서 개발한 API 클라이언트 SDK 통합
6. 기본 라우팅 구조 설정
7. 개발 환경 핫 리로드 구성

**통합 검증**:
- IV1: Dify 백엔드 API 연결 테스트 성공 (Story 0.5 SDK 사용)
- IV2: 기존 Docker Compose에 web-edu 서비스 추가 및 정상 작동
- IV3: 기존 시스템 성능에 영향 없음 확인
- IV4: 개발 서버 시작 시간 10초 이내
