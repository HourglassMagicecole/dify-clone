# 사용자 인터페이스 개선 목표

## 기존 UI와의 통합

EduAI Studio는 Dify의 복잡한 전문가용 인터페이스를 교육 목적에 맞게 완전히 재설계합니다. 기존 Dify UI의 기술 용어 과다, 복잡한 설정 옵션, 가파른 학습 곡선 문제를 해결하여 단계별 가이드, 시각화 중심, 즉각적 피드백을 제공하는 교육 특화 UI를 구현합니다. Dify의 강력한 백엔드 기능은 그대로 유지하면서 프론트엔드만 교체합니다.

## 수정/신규 화면 및 뷰

### 교육 참가자 화면
- 온보딩/튜토리얼 화면
- 5단계 Agent 생성 마법사
- 비주얼 Workflow 편집기
- RAG 파이프라인 시각화 대시보드
- 대화형/작업형 실행 인터페이스
- 개인 대시보드 (리소스, 사용량, 활동)

### 관리자 전용 화면
- 사용자/세션 관리 대시보드
- 교육 자료 관리 (샘플/템플릿)
- API Key 중앙 관리
- 실시간 모니터링 대시보드
- 일괄 작업 처리 화면

## UI 일관성 요구사항

- **컬러 시스템**: 교육 친화적 파스텔톤 기반
- **타이포그래피**: 가독성 높은 한글 폰트 우선
- **아이콘**: 직관적이고 친숙한 아이콘 세트
- **컴포넌트**: Material Design 3 기반 커스터마이징
- **인터랙션**: 프로그레시브 디스클로저, 인라인 도움말, 시각적 피드백, 드래그 앤 드롭
- **접근성**: WCAG 2.1 AA 준수, 키보드 네비게이션
- **반응형**: 1280px(데스크톱), 768px(태블릿) 브레이크포인트
