## Dev Notes

### 데이터베이스 스키마 정보
[Source: architecture/5-데이터-모델-및-스키마-변경.md]

#### 핵심 교육 관리 테이블 (4개)
1. **education_sessions**: 교육 세션 관리, UUID PK, session_code 유니크 인덱스
2. **education_enrollments**: 세션 참가자 관리, user_id+session_id 유니크 제약
3. **resource_tags**: 리소스 태깅 (멀티테넌트 대체), 태그 검색 인덱스
4. **learning_progress**: 학습 진도 추적, module별 진도율 관리

#### 관리 기능 테이블 (7개)
5. **education_templates**: 교육 자료 템플릿, JSONB config 필드
6. **education_api_keys**: API Key 중앙 관리, 암호화 저장 필수
7. **education_usage_limits**: 사용량 제한 설정, daily/monthly 한계
8. **education_usage_stats**: 사용 통계 수집, 비용 추정 포함
9. **education_activity_logs**: 활동 로그 추적, JSONB details
10. **user_education_roles**: 교육 역할/권한 관리
11. **education_achievements**: 성취/배지 시스템

### Flask-Migrate 명령어
[Source: architecture/5-데이터-모델-및-스키마-변경.md#마이그레이션-전략]
```bash
# 마이그레이션 생성
uv run --project api flask db migrate -m "Add education tables"
# 마이그레이션 적용
uv run --project api flask db upgrade
# 마이그레이션 상태 확인
uv run --project api flask db show
# 마이그레이션 히스토리
uv run --project api flask db history
# 롤백 (한 단계)
uv run --project api flask db downgrade -1
```

   - Impact: API 키 유출 시 전체 시스템 침해 가능

   - Impact: 권한 에스컬레이션 가능성
   - Recommendation: RBAC 구현 강화

### Performance Considerations

1. **PERF-001**: enrollments relationship에서 N+1 쿼리 발생 가능
   - Recommendation: selectinload 또는 joinedload 전략 적용

2. **PERF-002**: JSONB 필드 검색 성능
   - Recommendation: GIN 인덱스 추가
   ```sql
   CREATE INDEX ix_templates_config ON education_templates USING GIN (config);
   CREATE INDEX ix_progress_data ON learning_progress USING GIN (progress_data);
   ```
