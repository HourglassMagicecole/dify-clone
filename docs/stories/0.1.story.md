### 기술 스택 요구사항

#### 필수 런타임 및 도구

- **Node.js**: >=22.11.0 (pnpm 패키지 매니저)
- **Docker**: Docker Compose 오케스트레이션 지원

#### 백엔드 기술 스택
- **Flask**: 3.1.2 (Flask-SQLAlchemy, Flask-Migrate 포함)
- **Gunicorn**: 23.0.0 (gevent worker 사용)
- **Celery**: 5.5.2 (비동기 작업 처리)
- **PostgreSQL**: 최신 (Docker Compose로 관리)
- **Redis**: 최신 (Celery 브로커)

#### 프론트엔드 기술 스택
- **Next.js**: 15 (React 19 포함)
- **TypeScript**: strict 모드 필수
- **Tailwind CSS**: 3.x

### Docker 구성
[Source: architecture/9-인프라-및-배포-통합.md#docker-compose-통합]

Docker Compose 환경:
- `api`: Dify 백엔드 API (포트 5001)
- `web`: 기존 Dify 프론트엔드 (포트 3000)
- `web-edu`: 교육용 프론트엔드 (포트 3001)
- `redis-edu`: 교육 전용 Redis (포트 6380)
- 네트워크: `dify-network` 사용

### 환경 변수 설정
[Source: architecture/9-인프라-및-배포-통합.md#환경-변수-관리]

docker/.env.edu 파일 생성 필요:
```
EDU_SESSION_SECRET=your-secret-key
EDU_MAX_USERS=50
EDU_MAX_CONCURRENT_REQUESTS=50
EDU_API_RATE_LIMIT=1000
EDU_CORS_ORIGINS=http://localhost:3001
EDU_MONITORING_ENABLED=true
EDU_LOG_LEVEL=info
```

### 로컬 개발 설정
[Source: architecture/9-인프라-및-배포-통합.md#로컬-개발-설정]

개발 서버 실행 명령:
- 백엔드: `./dev/start-api`
- Worker: `./dev/start-worker`
- 프론트엔드: `cd web-edu && pnpm dev`

### 코드 품질 도구
[Source: architecture/9-인프라-및-배포-통합.md#코드-품질-도구]

필수 설정:
- Python: Ruff (linting & formatting), basedpyright (type checking)
- TypeScript: ESLint + Prettier

### Testing
[Source: architecture/11-테스팅-전략.md]

#### 테스트 실행 명령
백엔드:
```bash
uv run --project api pytest tests/unit_tests/
uv run --project api pytest tests/integration_tests/
```

프론트엔드:
```bash
cd web-edu && pnpm test
cd web-edu && pnpm test:e2e
```

#### 코드 품질 검사
```bash
./dev/reformat  # 모든 포매터 및 린터 실행
uv run --project api ruff check --fix ./
uv run --project api ruff format ./
uv run --directory api basedpyright
```
