### 백엔드 테스트 명령어
[Source: architecture/11-테스팅-전략.md#테스트-실행-명령]

```bash
# 백엔드 테스트
uv run --project api pytest tests/unit_tests/education/
uv run --project api pytest tests/integration_tests/education/

# 코드 품질
./dev/reformat                              # 모든 포매터 및 린터 실행
uv run --project api ruff check --fix ./   # 린팅 이슈 수정
uv run --project api ruff format ./        # 코드 포매팅
uv run --directory api basedpyright        # 타입 체크
```

### 프론트엔드 테스트 명령어
[Source: architecture/9-인프라-및-배포-통합.md#코드-품질-도구]

```bash
# 프론트엔드 테스트
cd web-edu
pnpm test                                   # Jest 테스트
pnpm test:e2e                              # E2E 테스트
pnpm lint                                   # ESLint 실행
pnpm eslint-fix                            # ESLint 이슈 수정
```

### Docker 빌드 설정
[Source: architecture/9-인프라-및-배포-통합.md#Dockerfile-for-web-edu]

멀티스테이지 빌드를 사용하여 이미지 크기를 최소화:
- base: Node.js 22 Alpine
- deps: 의존성 설치
- builder: 빌드 스테이지
- runner: 실행 스테이지 (최종 이미지)
